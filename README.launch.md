KowoPay is a mobile fintech platform built to simplify digital payments, wallet management, airtime purchases, bill payments, and everyday financial activity in one secure app experience.

## Why it matters

Modern users want speed, trust, and convenience. KowoPay brings those together in a clean Flutter application designed for account access, deposits, withdrawals, utility payments, and AI-assisted support.

## Core features

- Secure onboarding and authentication
- Wallet dashboard and account overview
- Instant deposits and withdrawals
- Airtime purchase and bill payment flows
- AI-powered help and support
- Profile, settings, and help center
- Firebase-backed app data and auth
- Flutterwave-ready payment integrations

## Tech stack

- Flutter / Dart
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage
- Riverpod
- Flutterwave
- Google Mobile Ads
- Google Generative AI

## Quick start

### Prerequisites

- Flutter SDK 3.x+
- Dart SDK
- Firebase project configured
- Android Studio or VS Code with Flutter tools

### Install

```bash
git clone https://github.com/Barusology/kowopay.git
cd kowopay
flutter pub get
```

### Run locally

```bash
flutter run
```

### Build

```bash
flutter build apk
flutter build ios
flutter build web
```
